# Sistem frizerskog salona

Seminarski projekat iz predmeta **Modelovanje podataka**, izrađen tokom prve godine studija. Tema projekta je modelovanje podataka za frizerski salon.

## Sadržaj projekta

U folderu `FFR3` nalaze se:

- PowerDesigner modeli podataka i objektni model;
- izveštaji za konceptualni, fizički i objektni model;
- XML šema;
- seminarski rad `finalno salon.docx`, koji objašnjava modele i prikazuje primere XML, JSON i CSV podataka.

## Otvaranje fajlova

Seminarski rad se otvara programom koji podržava `.docx` format. Modeli `.pdm` i `.oom` otvaraju se u **SAP PowerDesigner-u**. Izveštaji u `.html` i `.rtf` formatu mogu se pregledati zasebno.

Ovaj repozitorijum predstavlja projekat modelovanja podataka, a ne aplikaciju koja se pokreće.
